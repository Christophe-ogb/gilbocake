Le site web de Gilbo Cake est une véritable vitrine, conçue pour éveiller les papilles. Cette pâtisserie artisanale méritait une identité numérique à la hauteur de ses créations, avec une présentation claire des produits, une navigation fluide par catégorie et un parcours de commande simplifié. Le design privilégie la lisibilité et la présentation des gâteaux, tout en restant parfaitement adapté aux appareils mobiles.

Technologies : HTML5, CSS3, JavaScript

Caractéristiques principales : Catalogue de produits structuré, formulaire de contact et de commande, conception adaptative, expérience visuelle haut de gamme.
